# Piercer CLI Hex / PE / ELF Inspector (C++17)

Fast **C++17** command-line utility to inspect PE (Windows) and ELF (Linux) headers, calculate Shannon entropy per section, and print a formatted Hex Dump.

## How to Build

```bash
g++ -std=c++17 -O2 main.cpp -o piercer_cli_hex
# or via CMake:
cmake -B build && cmake --build build
```
