# Piercer CLI Hex / PE / ELF Inspector (C++17)

Ferramenta de linha de comando em **C++17** para inspecionar cabeçalhos PE (Windows) e ELF (Linux), calcular entropia de Shannon por seção e exibir Hex Dump no terminal.

## Como Compilar

```bash
g++ -std=c++17 -O2 main.cpp -o piercer_cli_hex
# ou via CMake:
cmake -B build && cmake --build build
```
